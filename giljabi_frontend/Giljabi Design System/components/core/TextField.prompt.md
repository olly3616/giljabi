Large-type input for the rare screen that needs typing.

```jsx
<TextField label="어디로 가시나요?" icon="search" placeholder="예: 부산" hint="역 이름을 적어주세요." />
```

- Label lives above the box, always. Placeholders are examples, not labels.
- Focus: border 2px → 3px blue-700 plus a 4px blue-100 halo.
- Errors carry an icon and text, and the message says what to do next.
