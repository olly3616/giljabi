# 길잡이 (Giljabi) — AI 디지털 약자 내비게이터

> 스마트폰을 어려워하는 사용자에게, **AI가 지금 화면을 보고 목표까지 한 단계씩 길을 안내**하는 안드로이드 앱.
> 자막 대신 **캐릭터 안내원**이 화면 위에서 눌러야 할 곳으로 직접 이동하며 가이드한다.

원티드 AI 챔피언십 2026 출품작 · MVP 데모: 코레일 승차권 예매 1개 흐름 완주

---

## 무엇이 다른가

| 차별점 | 설명 |
|---|---|
| **자립 코칭** | 대신 눌러주지 않고 사용자가 스스로 하도록 한 단계씩 안내 |
| **실제 화면 인식** | 매뉴얼이 아니라 사용자의 진짜 화면을 읽고 안내 → UI가 바뀌어도 대응 |
| **캐릭터 안내원** | 정서적 장벽 완화 + 시선을 정확한 위치로 유도 |
| **앱 무관 구조** | 특정 앱에 하드코딩하지 않고 화면 요소를 읽어 판단 |

## 아키텍처

```
[다른 앱: 코레일]  ←  사용자가 실제로 조작
   │                        ▲
   ▼ (화면 읽기)            │ (안내 표시)
접근성 서비스 '눈'      오버레이 '손'
   │                        ▲
   └──→  안내 컨트롤러 (코어 루프)  ──→  AI 판단 '두뇌'
              화면정보 → AI 호출 → 캐릭터 제어
```

- **눈 (F1):** `AccessibilityService` — 화면 UI 요소의 텍스트·좌표·클릭가능 여부 수집
- **두뇌 (F3):** LLM API — `{목표 + 화면요소 + 진행상태}` → `{target_text, guidance_text, is_goal_reached}`
- **손 (F4):** `WindowManager` 오버레이 — 캐릭터·말풍선·하이라이트를 다른 앱 위에 렌더링
- **음성 (F5):** Android `TextToSpeech`
- **루프 (F6):** 화면 전환 감지 → 재판단 반복

## 기술 스택

| 영역 | 선택 |
|---|---|
| 언어/플랫폼 | Kotlin, 안드로이드 네이티브 (minSdk 26 / targetSdk 34) |
| 빌드 | Gradle (Kotlin DSL) + Android Gradle Plugin |
| UI | Android Views + ViewBinding, Material 3 |
| 화면 인식 | AccessibilityService |
| 오버레이 | WindowManager + `SYSTEM_ALERT_WINDOW` |
| AI | LLM API (인터페이스 추상화 — 구현체 교체 가능) |
| 음성 | Android TextToSpeech |

## 저장소 구조

```
giljabi/
├── giljabi_frontend/           # 안드로이드 앱 (본체)
│   ├── app/                    # 앱 모듈
│   └── Giljabi Design System/  # 디자인 시스템 (토큰·컴포넌트·가이드라인 참조본)
├── giljabi_backend/            # (선택) LLM API 프록시 — 키 보호용
└── 01~06_*.md                  # 기획·명세·아키텍처·일정 문서
```

## 개발 로드맵

| 마일스톤 | 목표 |
|---|---|
| **M0** | 프로젝트 스캐폴딩 + 디자인 토큰 이식 ✅ |
| **M1** | 파이프라인 뚫기 — 접근성으로 화면 읽고 오버레이에 마커 표시 |
| **M2** | 코어 루프 — AI 판단 → 안내(마커+말풍선+TTS) |
| **M3** | 코레일 완주 + 캐릭터 애니메이션 |
| **M4** | 데모 안정화 + 발표 |

## 빌드

```bash
cd giljabi_frontend
./gradlew assembleDebug      # APK 빌드
./gradlew installDebug       # 연결된 실기기에 설치
```

> 실행에는 접근성 서비스 권한 + 화면 오버레이 권한을 기기 설정에서 직접 켜야 합니다.
