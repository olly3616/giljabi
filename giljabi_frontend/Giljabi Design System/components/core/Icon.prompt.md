Bold-stroke Lucide glyph, used everywhere an action or a goal needs a picture beside its label.

```jsx
<Icon name="train-front" size="lg" color="var(--blue-600)" label="기차표" />
```

- Sizes: `sm` 24 / `md` 32 / `lg` 48 / `hero` 64, or a number.
- Icons are always paired with a text label — never the only signal for state or meaning.
- Requires the Lucide UMD script on the page.
